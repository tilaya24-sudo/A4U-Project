Publishing Workflow

1. Select a page and edit sections or design settings. 2. Upload media and attach it to a section. 3. Save your draft and preview. 4. Publish to update the live website.

Your GitHub/Vercel deployment serves the site code; published content is loaded from Supabase. Editing content does not require a Git commit or redeployment once it is set up.
